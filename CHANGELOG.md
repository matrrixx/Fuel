# История изменений

## 1.3.0
- Работа без интернета (service worker), установка как приложение на Android и iPhone.

## 1.2.0
- Панель норм (кнопка ⚙): можно менять названия и значения норм, добавлять и удалять строки, сбрасывать к исходным. Настройки хранятся на устройстве.

## 1.1.0
- Блок «Пробег по одометру»: начало, конец, сколько проехано и сколько осталось распределить.
- Иконка сайта и иконка для экрана «Домой».
- Структура репозитория: разделены HTML, CSS, JS и настройки норм.
- Автоматический деплой на GitHub Pages.

## 1.0.0
- Расчёт расхода по трём нормам с выбором температуры (+/−), итог и общий пробег.
